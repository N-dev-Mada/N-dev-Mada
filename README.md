### 🌟 Produits Phares de la Suite `N-product`

#### 💬 1. [Messagerie-Local](https://github.com/N-dev-Mada/Messagerie-Local) (`N-product #1`)
> **WhatsApp Web Clone LAN — Application de messagerie instantanée 100% autonome et résiliente pour réseaux locaux.**

- 🖼️ **Architecture Anti-OOM :** Compression WebP automatique côté client via Canvas HTML5.
- 🗄️ **Moteur SQLite WAL :** Persistance locale rapide avec requêtes préparées via `node:sqlite`.
- 🎙️ **Multimédia & Vocaux :** Traitement Web Audio HTML5, onde sonore interactive et lecteur variable.
- 📱 **PWA & LAN :** Déploiement multi-interface `0.0.0.0` et connexion smartphone instantanée par QR Code.
- ⚡ **Temps Réel :** Canal persistant léger via Server-Sent Events (SSE).

---

#### 🎨 2. [Portfolio-Universel](https://github.com/N-dev-Mada/Portfolio-Universel) (`N-product #2`)
> **Visual Portfolio Builder — Single Page Application (SPA) No-Code / WYSIWYG ultra-performante.**

- 🎨 **Éditeur Visuel Intégré :** Modification directe des couleurs, typographies, presets de profils et sections.
- ✉️ **Formulaire Hybride :** Envoi vers API distante configurée ou fallback automatique `mailto:` pré-rempli.
- 💾 **Gestion des Données :** Configuration centralisée en JSON (`portfolio-config.json`) avec import/export.
- 🚀 **Performance 60 FPS :** Détection de défilement fluide via `IntersectionObserver` sans surconso DOM.
- ⚡ **Stack Moderne :** Construit avec React 19, TypeScript strict, Vite 6 et Tailwind CSS v4.
